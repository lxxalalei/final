# 儿童学习领域语义词表

本词表用于理解口语、归一化概念和识别可能歧义，不是固定分类器，也不直接生成搜索查询。

## 数学

| 用户表达 | 规范概念 | 可能目标 |
|---|---|---|
| 算术、口算、计算 | 数学基础计算 | 整数、小数、分数或具体运算范围 |
| 加减乘除、四则运算 | 基础运算 | 同步练习、专项训练 |
| 文字题、解决问题 | 应用题 | 单步、多步或典型数量关系 |
| 奥数、思维题 | 数学思维/竞赛 | 进阶或竞赛；不要默认适合普通同步学习 |
| 图形、空间、几何 | 几何与空间 | 认知、推理、测量 |

“数学不好”不是用户主动指定的学习内容，需要结合上下文判断计算、应用题还是具体数学概念。

## 范围外表达

专注力、时间管理、作业习惯、拖延、笔记、记忆、检查、答题方法，以及泛化的情绪、行为和亲子关系问题，不归一化为学习内容。没有任何受支持学习内容时保持 `needs_clarification`，询问用户希望资源具体覆盖什么学科、主题或能力；同时存在具体学科内容时，只保留用户明确指定的学科内容。

## 安全教育

常见方向：交通、防溺水、消防、防拐、网络安全、身体边界、校园安全。

安全主题不能因“儿童”而自动确定年龄；不同年龄的表达和内容尺度差异较大。用户未提供年龄且主题敏感时，可根据影响测试决定是否澄清。

## 使用纪律

1. 保留用户原词作为 evidence.quote。
2. 规范概念用于 clarified_need 和 evidence.statement。
3. 一个定向需求存在多种内容路线时澄清；用户主动要求广泛收集时保留其粒度。
4. 不从词表自动推出平台、查询句或资源质量。
