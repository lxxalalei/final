# resource-intent · 需求理解与查询生成

## 职责
将用户的自然语言学习需求，转化为结构化的搜索查询指令组。
包含**需求澄清、语义理解、多维度查询生成**三个核心环节。

> 💡 设计思路：从"分类器"变成"翻译器"——不预设分类，不强制用户选类别，核心是把家长模糊、口语化的需求，翻译成一组能直接去搜的关键词。

## 输入
- 用户原始需求文本
- （可选）多轮对话上下文

## 执行步骤

### 第一步：需求清晰度判断
判断用户需求是否已经足够具体，是否需要澄清。
- 判断规则见：`references/需求拆解规则.md` 第三节

**足够具体 → 直接进入第三步，跳过澄清。**
**不够具体 → 进入第二步。**

### 第二步：需求澄清（最多 2 轮）
通过 1-2 轮对话，把模糊需求收敛到可搜索的具体主题。

**第 1 轮（必问）**：把核心诉求搞清楚
- 用开放式问题引导，不要用封闭式选项
- 话术选择见：`references/澄清话术库.md`

**第 2 轮（可选，最多 1 个）**：补充最关键的一个信息
- 优先级：使用场景 > 期望效果 > 年龄/基础 > 其他偏好
- 第 3 轮及以后：禁止，宁可搜不准也不要问烦了

### 第三步：语义理解与槽位抽取
从用户自然语言中提取关键信息（主题、目标、类型、难度等）。
- 槽位定义与抽取规则见：`references/需求拆解规则.md` 第四节

### 第四步：默认补全
用户未明确的维度，按通用最优策略自动补全。
- 默认补全规则见：`references/需求拆解规则.md` 第五节

### 第五步：五维拆解生成查询
按「核心主题、资源形态、受众难度、来源倾向、使用场景」五个维度，生成差异化查询指令。
- 五维拆解法详见：`references/需求拆解规则.md` 第六节
- 主题扩展词表见：`references/主题扩展词表.md`

**要求**：单需求至少生成 10 个差异化查询，覆盖至少 3 种资源形态。

### 第六步：去重排序与输出
合并相似查询，按优先级排序，输出结构化查询指令组。

## 关键原则

### 澄清原则
- **最少澄清**：能不问就不问，能猜就猜，猜了要说明假设
- **一次一问**：一轮只问一个问题，不要连发三问
- **开放引导**：用开放式问题引导，不要用封闭式选项框住用户
- **最多两轮**：最多问 2 个问题，问不完就用默认值
- **搜索优先**：搜索的成本比追问低，70% 清楚就可以开搜

### 拆解原则
- **语义优先**：用语义理解抽取意图，不做关键字匹配
- **穷尽召回**：多角度、多形态扩展，宁可多不可漏
- **假设透明**：使用默认假设时，必须明确告知用户

## 适用范围
面向 3-12 岁儿童成长相关的所有需求，包括但不限于：
- 学科学习、科普启蒙、人文历史
- 艺术美育、思维训练、兴趣拓展
- 习惯品格、情绪管理、安全教育
- 任何有助于孩子成长的内容

## 输出格式
```
【需求理解】
一句话总结：用 1-2 句话概括用户的核心诉求

【核心主题】XXX

【搜索参数】（给下游 search 用的结构化参数）
- 🎯 查询总数：XX 个
- 📋 资源形态：视频、图文、文档...
- 👶 目标年龄：X-X 岁（用户明确 / 默认假设）
- 📊 难度偏好：入门/进阶/系统（用户明确 / 默认假设）
- 🏢 来源偏好：不限/官方优先/视频平台优先（用户明确 / 默认假设）
- ⚡ 搜索模式：标准模式 / 穷尽模式
- 💡 重点方向：（比如"优先找动画视频"、"重点搜官方站点"）

【查询列表】（按优先级分级，下游 search 按级执行）

【核心查询】（优先级最高，必须搜）
1. XXX
2. XXX
3. XXX

【官方定向】（去白名单官方站点搜）
4. XXX
5. XXX

【形态定向】（分别限定不同资源形态）
6. XXX（视频）
7. XXX（文档）
8. XXX（图文）

【长尾补充】（优先级较低，有空再搜）
9. XXX

...

【假设说明】
- ✅ 用户明确：列出用户明确说过的信息
- 💡 默认假设：列出模型自动补全的假设（如果不对可以调整）
```

## 写入文件

### 1. 获取任务路径
- 从 flow 传入参数中获取：会话目录 `{session_dir}`、输出文件名（通常 `stage1_intent.json`）
- 本阶段无上游文件

### 2. 分析需求并生成查询
- 阅读用户原始需求
- 生成分级查询列表（core/official/format/longtail）
- 做出的默认假设写入 `assumptions`

### 3. 写入结果文件

将以下结构写入 `{session_dir}/stage1_intent.json`：

```json
{
  "_meta": {
    "stage": 1,
    "session_id": "{session_id}",
    "skill": "resource-intent",
    "created_at": "ISO时间",
    "input_from": null
  },
  "_summary": {
    "core_topic": "核心主题",
    "query_count": 3,
    "target_age": "8-9岁",
    "search_mode": "standard"
  },
  "data": {
    "summary": "一句话需求总结",
    "core_topic": "核心主题",
    "queries": [
      {"text": "查询关键词", "tier": "core/official/format/longtail", "format_hint": "视频/音频/文档/图文"}
    ],
    "target_age": "目标年龄范围",
    "grade_level": "年级",
    "difficulty": "入门/进阶/系统",
    "format_preferences": ["视频", "文档"],
    "source_preference": "不限/官方优先/视频平台优先",
    "search_mode": "standard / exhaustive",
    "assumptions": ["假设1", "假设2"]
  }
}
```

- `_summary`（flow 读这个）：核心主题、查询数量、目标年龄、搜索模式
- `data`（下游 search 读这个）：需求总结、核心主题、查询列表、年龄/年级/难度、偏好、假设清单

### 4. 完成后

- 提示 flow 调用 `resource-search` 继续执行
- 只返回 `_summary`，不在上下文中展开完整 data
