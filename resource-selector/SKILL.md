# resource-selector · 候选展示与用户选择

## 概述

本 Skill 负责将搜索调度器返回的候选资源，以清晰、友好的方式展示给用户，
支持多种选择方式，并输出结构化的选定资源列表给下载调度器。

**上游**：resource-search（搜索调度器）
**下游**：resource-downloader（下载调度器）

---

## 核心职责

1. **结构化展示**：将候选资源按平台、类型、质量分级分类展示
2. **信息透明**：每个资源标注质量等级、下载难度、来源平台等关键信息
3. **灵活选择**：支持多种选择方式（编号、全部、按类型、按质量等）
4. **确认机制**：用户选择后先确认再下载，避免误操作
5. **结构化输出**：输出符合统一元数据规范的选定资源列表

---

接收来自 resource-search 的候选资源列表，每个资源符合统一元数据规范。

**输入示例：**

{
  "total_count": 22,
  "search_summary": "搜索了 5 个平台，共召回 79 条，初筛后 45 条，最终精选 22 条",

## 展示规则

### 排序原则

1. **质量优先**：S级 → A级 → B级 → C级
2. **同质量内**：下载可行性高的优先
3. **同平台内**：按热度/播放量排序

### 分类方式

优先按**平台**分类展示，其次按**资源类型**分类。
如果资源数量多（>15个），可以先按平台分，每个平台内再按质量排序。

### 数量展示

- 默认展示全部候选（标准模式20-25个，穷尽模式30-40个）
- 如果超过 30 个，可以先展示 TOP 20，再问用户是否要看更多
- 必须告诉用户总共有多少个候选

## 单条资源展示格式

### 完整格式（推荐）

```
1. ⭐ S级：小学必背古诗文动画（228集全）
   📍 平台：B站
   📊 难度：⚠️ 中（可能需要重试，建议选备用）
   👀 播放：500万+ | ⏱️ 时长：共228集
   💡 推荐理由：动画形式，孩子容易接受，覆盖小学全部必背古诗
   🔗 链接：https://www.bilibili.com/video/BV1xx...
```

### 简化格式（候选多时用）

```
1. ⭐ S级 小学必背古诗文动画（228集） [B站 · 难度中 · 500万+播放]
   链接：https://www.bilibili.com/video/BV1xx...
```

### 字段说明

| 标识 | 字段 | 说明 |
|------|------|------|
| ⭐ S/A/B/C | 质量等级 | 调度器校准后的最终质量等级 |
| 📍 平台 | 来源平台 | 用户一眼知道来自哪里 |
| 📊 难度 | 下载可行性 | 高/中/低，让用户有预期 |
| 👀 播放 | 播放/浏览量 | 侧面反映受欢迎程度 |
| ⏱️ 时长 | 时长/集数 | 视频/音频类显示 |
| 💡 推荐理由 | 内容简介 | 1-2句话说明为什么推荐 |
| 🔗 链接 | 来源URL | 用户可以自己先点开看看 |

---

## 下载难度标识

| 等级 | 标识 | 说明 | 提示语 |
|------|------|------|--------|
| 高 | ✅ 高 | 基本可以成功下载 | "下载成功率高" |
| 中 | ⚠️ 中 | 可能需要重试或降级 | "可能需要重试，建议选1-2个备用" |
| 低 | ❌ 低 | 大概率下不了 | "下载难度大，可能只能保存摘要" |

**展示原则**：
- 难度为"低"的资源，必须明确提醒用户
- 建议用户搭配选择：高难度的选几个，中低难度的也选几个备用
- 如果用户选的全是低难度的，主动提醒并建议增加一些高难度的

## 选择方式

### 1. 编号选择

**支持格式：**
- 单个：`1`
- 多个逗号分隔：`1,3,5`
- 多个空格分隔：`1 3 5`
- 范围：`1-5`（选1到5号）
- 混合：`1,3-5,7`

**示例：**
```
用户：1,3,5
→ 选中第1、3、5号资源
```

### 2. 全部选择

**指令：** `全部`、`全选`、`都要`、`所有`

**示例：**
```
用户：全部
→ 选中所有22个资源
```

### 3. 按类型筛选

**指令：** `视频`、`音频`、`文档`、`练习题`、`图文`

**示例：**
```
用户：视频
→ 选中所有视频类资源
```

### 4. 按质量筛选

**指令：** `S级`、`A级`、`S和A级`、`高质量`

**示例：**
```
用户：S级
→ 选中所有S级资源
```

### 5. 按平台筛选

**指令：** `B站`、`喜马拉雅`、`知乎`

**示例：**
```
用户：B站
→ 选中所有B站的资源
```

### 6. 按下载难度筛选

**指令：** `高难度`、`容易下的`、`稳的`

**示例：**
```
用户：稳的
→ 选中所有下载难度为"高"的资源
```

### 7. 取消选择

**指令：** `不要了`、`算了`、`取消`、`不下载了`

---

## 确认机制

用户选择后，必须先确认再进入下载阶段。

**确认格式：**
```
✅ 已为您选择 X 个资源：

1. [资源1标题] [平台]
2. [资源2标题] [平台]
...

准备开始下载，确认吗？
• 回复"确认"开始下载
• 回复"取消"重新选择
• 回复"加几个"继续添加
• 回复"去掉X"去掉某个
```

---

## 输出格式

用户确认后，输出结构化的选定资源列表给下载调度器。

**输出格式（符合统一元数据规范）：**
```json
{
  "selected_count": 5,
  "selection_mode": "manual",
  "resources": [
    {
      "resource_id": "bilibili:BV1xx411c7mD",
      "title": "小学必背古诗文动画（228集全）",
      "type": "视频",
      "subject": "语文",
      "platform": "bilibili",
      "source_url": "https://www.bilibili.com/video/BV1xx411c7mD",
      "source_name": "B站",
      "quality_level": "S",
      "download_feasibility": "中",
      "description": "动画形式讲解小学必背古诗，覆盖全部228首",
      "tags": ["古诗", "动画", "系统课程"]
    },
    ...
  ]
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| `selected_count` | 选中的资源总数 |
| `selection_mode` | 选择方式：manual（手动编号）/ all（全部）/ by_type（按类型）/ by_quality（按质量） |
| `resources` | 选中的资源列表，每个资源符合统一元数据规范 |

## 异常处理

### 用户输入无法识别

如果用户输入的选择指令无法识别：
```
抱歉，我没理解您的选择 😅

可以这样选：
• 回复数字编号（如：1,3 或 1-5）
• 回复"全部"下载所有
• 回复"视频"只选视频类
• 回复"S级"只选S级
• 回复"不要了"取消下载
```

### 选的全是低难度的

主动提醒：
```
⚠️ 提醒：您选的 X 个资源里，有 X 个下载难度是"低"的，大概率可能下不了。

建议再选几个下载难度"高"或"中"的备用，避免都下失败了没的用。
需要我帮您推荐几个吗？
```

### 选的数量太多

如果选了超过 10 个，主动确认：
```
您选了 X 个资源，数量有点多哦，下载可能需要比较长时间。

确认要全部下载吗？
• 回复"确认"全部下载
• 回复"选前10个"只下载质量最高的10个
• 回复"取消"重新选择
```

## 设计原则

### 1. 信息透明
每个资源的关键信息（质量、难度、平台）都要明确展示，让用户心里有数。

### 2. 选择灵活
支持多种选择方式，满足不同用户的习惯。

### 3. 防误操作
有确认机制，避免用户手滑选错。

### 4. 友好提示
对可能的问题（低难度、数量多）主动提醒，降低用户预期。

### 5. 结构化输出
输出格式严格遵循统一元数据规范，确保下游 downloader 可以直接使用。

## 读写文件

### 1. 获取任务路径
- 从 flow 传入参数中获取：会话目录 `{session_dir}`、上游文件名（通常 `stage2_search.json`）、输出文件名（通常 `stage3_select.json`）

### 2. 读取上游数据
- 读取 `{session_dir}/stage2_search.json` 的 `data` 部分
- 提取候选资源列表用于展示给用户

### 3. 用户选择后写入结果

用户确认选择后，将以下结构写入 `{session_dir}/stage3_select.json`：

```json
{
  "_meta": {
    "stage": 3,
    "session_id": "{session_id}",
    "skill": "resource-selector",
    "created_at": "ISO时间",
    "input_from": "stage2_search.json"
  },
  "_summary": {
    "selected_count": 5,
    "selection_mode": "manual",
    "by_platform": {"bilibili": 2, "ximalaya": 3}
  },
  "data": {
    "selected_count": 5,
    "selection_mode": "manual / all / by_type / by_quality",
    "resources": [
      {
        "// 说明": "保留 stage2 中该资源的全部字段",
        "resource_id": "...",
        "title": "...",
        "type": "...",
        "subject": "...",
        "platform": "...",
        "source_url": "...",
        "source_name": "...",
        "quality_level": "...",
        "download_feasibility": "...",
        "...": "（stage2 的所有字段原样保留）"
      }
    ]
  }
}
```

- `_summary`（flow 读这个）：选中数量、选择方式、平台分布
- `data`（下游 downloader 读这个）：用户选中的资源列表
- **保留规则**：只做筛选不做裁剪，保留的每个资源要带过来上游的全部字段，一个字段都不能删

### 4. 完成后

- 提示 flow 调用 `resource-downloader` 继续执行
- 只返回 `_summary`，不在上下文中展开完整 data
