# 展示模板与话术

## 为什么需要模板和话术

同样的内容，不同的展示方式，用户体验天差地别。
- 好的展示：清晰、易读、好选择
- 差的展示：混乱、信息过载、不知道怎么选

**目标**：让用户一眼看懂，一秒做出选择。

## 各类型资源的展示要点

### 📹 视频类资源

**必须展示的信息**：
- 视频时长（单集/总时长）
- 集数（如果是系列）
- 讲解形式（真人/动画/板书）
- 语言（中文/英文）
- 是否有字幕

**推荐理由怎么写**：
- 讲解清晰，孩子容易理解
- 动画形式有趣，不枯燥
- 系统完整，适合打基础
- 每集时间短，适合注意力

## 选择方式说明话术

### 标准版本（最常用）

```
💡 选择方式：
- 回复数字编号（如：1,3 或 1 3）
- 回复"全部"下载所有
- 回复"视频"只选视频类
- 回复"练习题"只选练习题类
- 回复"不要了"取消下载
```

### 精简版本（候选少时用）

```
💡 回复数字编号选择（如：1 或 1,3），或回复"全部"下载所有
```

### 详细版本（第一次使用时用）

```
💡 怎么选？
- 选单个：回复 "1"
- 选多个：回复 "1,3" 或 "1 3 5"
- 选一段：回复 "2-5"（选第2到第5个）
- 选全部：回复 "全部"
- 按类型选：回复 "视频" 或 "练习题"
- 不选了：回复 "不要了"
```

## 推荐理由写作技巧

### 技巧 1：结合用户需求

不要写通用的推荐理由，要结合用户的具体需求。

❌ 不好：
> "推荐理由：内容很好"

✅ 好：
> "推荐理由：正好匹配你要的四则混合运算，从入门到进阶都有，适合零基础开始学"

---

### 技巧 2：具体，不空洞

说清楚好在哪里，不要空泛的"很好""不错"。

❌ 不好：
> "推荐理由：这个资源不错"

✅ 好：
> "推荐理由：题量充足（20页约200道题），题型丰富（口算、脱式、应用题都有），带详细答案解析"

---

### 技巧 3：突出核心优势

每个资源都有它最突出的优点，把那个说出来。

✅ 好的例子：
> "推荐理由：官方平台出品，完全免费，无广告，内容系统完整"
> "推荐理由：动画形式有趣，孩子一看就懂，不枯燥"
> "推荐理由：可直接下载PDF，打印出来就能做，很方便"
> "推荐理由：讲解特别清晰，零基础也能听懂"

---

### 技巧 4：用孩子的视角

儿童资源，从孩子的角度说为什么好。

✅ 好的例子：
> "推荐理由：动画形式有趣，孩子喜欢看，不会觉得枯燥"
> "推荐理由：每集5分钟，适合孩子的注意力时长"
> "推荐理由：故事形式，孩子听着听着就学会了"

## 风险提示话术

### 付费提示

```
⚠️ 提示：完整课程可能需要付费，基础内容免费

```

### 广告提示

```
⚠️ 提示：页面可能有广告，请注意甄别

```

```

```

## 总结

展示和话术的核心是：
1. **清晰易读**：格式整齐，信息分层，一眼看懂
2. **信息完整**：该有的字段都有，不缺关键信息
3. **重点突出**：好的放前面，推荐理由说清楚
4. **选择方便**：多种选择方式，用户怎么方便怎么来
5. **风险透明**：有问题提前说，不隐瞒
6. **语气友好**：像朋友推荐，不像机器输出
