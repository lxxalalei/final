## 设计说明

白名单中的站点均为**无专属搜索 API** 的优质站点。search 阶段为这些站点生成 `tier: official` 查询（使用 `site:域名` 语法），由下游 platforms 阶段的 generic 通用搜索引擎执行。

已有专属平台 API 的站点（bilibili、ximalaya、smartedu、open163、zhihu、douyin、weibo）不在本列表中，它们在平台选择阶段直接作为独立平台被分发。

## 官方站内容筛选标准

供 search 阶段在生成 official 查询时参考，判断站点是否值得定向搜索。

**值得搜的**：系统课程、系列课、专题合集、互动学习资源、虚拟展厅、在线实验、纪录片、公开课

**谨慎搜的**：单篇科普文章（除非特别好）、图文介绍、知识点汇总

**不值得搜的**：新闻稿、活动通知、发布会、线下展品介绍、场馆介绍、卖书卖课广告、工作动态
