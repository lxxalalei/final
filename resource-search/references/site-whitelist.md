# 通用搜索的来源发现指南

本文件供 generic 生成必要的 `site:` 查询。它不是封闭白名单：模型可以依据当前主题发现其他可信来源，也可以搜索尚无独立适配器的平台公开页面。

## 可优先考虑的来源类型

- 公共教育与官方资源：`basic.smartedu.cn`、`eduyun.cn` 及各级公共教育机构网站。
- 科学、人文与公共文化：博物馆、科技馆、图书馆、大学、研究机构和专业学会网站，例如 `kepuchina.cn`、`cdstm.cn`。
- 公共媒体与少儿内容：国家级或地方公共媒体的教育、少儿、文化栏目，例如 `cctv.com`。
- 出版、阅读与专业儿童服务：出版社、儿童阅读机构、专业公益组织的公开内容。
- 尚未接入的公开平台页面：在确有资源价值时，可搜索 `wenku.baidu.com`、`xiaohongshu.com` 等可被搜索引擎索引的页面。

## 使用规则

1. 先判断来源与当前学习任务是否匹配，不逐站扫描。
2. 一个站点只代表来源线索，不代表其结果天然相关、免费、适龄或高质量。
3. 优先使用能发现具体有用资源的查询，不为了权威感把所有搜索都限制在机构网站。
4. 独立适配器不可执行或不存在时，可以用 generic 发现其公开页面，但不得伪造成独立平台任务。
5. 用户明确指定来源时保留该条件；用户没有指定时允许跨来源探索。
