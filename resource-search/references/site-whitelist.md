# 通用搜索的来源发现指南

本文件只帮助 generic 判断何时定向来源，不是封闭白名单，也不规定固定权重或逐站搜索数量。具体资源仍由 Selector 审查。

## 来源层次

### 原始与公共来源

- 国家智慧教育公共服务平台、各级教育公共服务网站；
- 政府部门、博物馆、科技馆、图书馆、大学、研究机构、专业学会；
- 公共媒体、出版社及作品或项目的官方页面。

适合原文、课程目录、科学事实、公共文化资源和机构活动。示例域名包括 `basic.smartedu.cn`、`eduyun.cn`、`kepuchina.cn`、`cdstm.cn`、`cctv.com`。

### 专业整理与儿童内容来源

- 有清晰作者、机构和编辑责任的科普、阅读、教育或儿童服务网站；
- 能提供结构化专题、图文解释、活动材料或可复用内容的公益与专业机构。

适合把专业内容转化为孩子可用资源，但“儿童”“教育”标签本身不代表质量。

### 平台公开页面与用户内容

在确有独特资源价值时，可通过网页索引发现 `wenku.baidu.com`、`xiaohongshu.com` 等尚无独立适配器的平台页面。它们适合补充具体文件、生活化活动或经验线索，不应取代原始来源，也不能预设免费、完整或准确。

## 使用规则

1. 先确定所缺的来源类型，再选择可能高密度的站点，不按名单逐个扫描。
2. 权威来源优先用于需要事实、原文和结构的方向；讲解和创作内容可保留多样来源。
3. `site:` 只有在能显著提高目标资源密度时使用；不要为权威感限制所有查询。
4. planned、未注册或暂不可独立执行的平台只能由 generic 发现公开页面。
5. 用户指定来源时保留；未指定时允许发现名单外的可信来源。
6. 来源层次是搜索策略，不是质量分数。单条资源的相关性、适龄性、完整性和可用性由下游判断。
