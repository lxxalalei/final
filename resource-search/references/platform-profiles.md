## 二、逐平台档案

### bilibili（B站）

| 项目 | 说明 |
|------|------|
| **域名** | bilibili.com |
| **资源形态** | 长视频、合集、番剧、教程 |
| **搜索能力** | 站内 API 搜索，支持按播放量、弹幕数、点赞等排序，支持分页 |
| **儿童内容丰富度** | 非常高，各年龄段都有大量优质内容，科普/兴趣类首选 |
| **登录要求** | 大部分公开视频不需要登录 |
| **典型场景** | 科普动画、系统课程、教学讲解、纪录片、兴趣入门 |

**擅长主题**：科普启蒙、学科讲解、思维训练、艺术美育、兴趣拓展

**擅长形态**：视频（动画/讲解/合集/课程）

**关键词风格**：支持中文自然语言，标题匹配为主。加"动画""讲解""课程""合集"等形态词。

示例：
- `"小学古诗 动画"` / `"三年级数学 讲解"` / `"恐龙科普 纪录片"`

### ximalaya（喜马拉雅）

| 项目 | 说明 |
|------|------|
| **域名** | ximalaya.com |
| **资源形态** | 音频专辑、系列故事、听读课程 |
| **搜索能力** | 公开 JSON API（revision/search），支持按相关度/播放量/最新排序，支持专辑/声音两种类型，支持免费过滤，支持分页 |
| **儿童内容丰富度** | 非常高，音频类儿童内容是主力 |
| **登录要求** | 搜索不需要；部分音频需 VIP |
| **典型场景** | 睡前故事、古诗国学听读、英语磨耳朵、儿歌、习惯品格故事 |

**擅长主题**：古诗国学、习惯品格、安全教育、英语听力

**擅长形态**：音频（故事/朗诵/课程/儿歌）

**关键词风格**：专辑名/主播名，加"儿童""启蒙""听""专辑"等词。

示例：
- `"小学必背古诗词"` / `"古诗 儿童朗诵"` / `"睡前故事 三年级"`

### smartedu（国家中小学智慧教育平台）

| 项目 | 说明 |
|------|------|
| **域名** | basic.smartedu.cn |
| **资源形态** | 课程视频、课件、练习题、专题教育 |
| **搜索能力** | 官方 API 搜索，按学科、年级、版本分类，支持分页 |
| **儿童内容丰富度** | 高，学科同步内容很全，和教材同步 |
| **登录要求** | 部分功能需要，Token 可选 |
| **典型场景** | 学科同步学习、课后复习、官方课程、教材配套 |

**擅长主题**：学科同步（首选）、安全教育

**擅长形态**：文档课件、视频课程、练习题

**关键词风格**：按教材目录结构，学科+年级+版本，正式表述。

示例：
- `"语文 三年级 人教版"` / `"数学 上册"` / `"安全教育 六年级"`

### open163（网易公开课）

| 项目 | 说明 |
|------|------|
| **域名** | open.163.com |
| **资源形态** | 公开课、纪录片、TED、大学课程 |
| **搜索能力** | 服务端渲染 HTML 解析，无需登录/Cookie/签名，纯 HTTP 请求 |

**擅长形态**：视频（公开课/纪录片/系列课）

**关键词风格**：课程名/讲师名，加"公开课""纪录片""儿童""青少年"等词筛选适龄内容。

### generic（通用兜底）

| 项目 | 说明 |
|------|------|
| **资源形态** | 所有类型 |
| **搜索方式** | 通用搜索引擎（百度、必应） |
| **适用场景** | 没有对应平台专属能力的所有网站，包括白名单站点的 site: 定向搜索 |
| **必选说明** | **始终加入平台组合**。执行白名单站点的 official 查询（site: 定向）和通用网页搜索，保证专属平台之外的信息也能被召回 |
| **限制** | 没有平台专属优化，成功率和质量可能不如专属平台 |

支持高级搜索语法：
- `site:域名 关键词` — 在指定站点内搜索
- `filetype:pdf 关键词` — 按文件类型搜索
- `"精确短语" 关键词` — 要求核心词完整出现

## 三、路由速查表

### 3.1 theme_type → 第一梯队平台

直接使用 intent 传来的 `theme_type`，不需要重新判断。

| theme_type | 第一梯队平台 | 原因 |
|------------|------------|------|
| 科普 | bilibili、open163、zhihu | 视频是科普主力 |
| 学科 | smartedu、bilibili | 官方+讲解双保险 |
| 古诗语文 | bilibili、ximalaya、smartedu | 听读+动画+官方 |
| 思维训练 | bilibili、zhihu | 视频演示+图文方法 |
| 艺术美育 | bilibili、douyin | 视觉类内容 |
| 习惯品格 | ximalaya、bilibili | 听故事+看动画 |
| 兴趣拓展 | bilibili、zhihu | 视频教程+图文经验 |
| 综合 | bilibili、ximalaya | 通用覆盖 |

### 3.2 format_preferences → 补充平台

| format_preferences 包含 | 补充平台 |
|------------------------|---------|
| 视频 | bilibili、open163 |
| 音频 | ximalaya |
| 文档/课件 | smartedu |
| 图文 | zhihu、weibo |
| 短视频 | douyin |
| 练习题 | smartedu、generic（filetype:pdf） |

### 3.3 source_preference → 优先平台

| source_preference | 优先平台 |
|-------------------|---------|
| 官方优先 | smartedu |
| 视频平台优先 | bilibili、open163 |
| 音频平台优先 | ximalaya |
| 综合覆盖 | 不指定优先，按主题匹配选 |

### 3.4 平台组合推荐

**标准组合**（大多数需求）：bilibili（视频）+ ximalaya（音频）+ zhihu/小红书（图文）+ generic 兜底

**学科同步组合**：smartedu（官方）+ bilibili（讲解视频）+ zhihu（学习方法）+ generic 兜底

**古诗国学组合**：ximalaya（音频听读）+ bilibili（动画视频）+ generic 兜底

**科普启蒙组合**：bilibili（动画视频）+ open163（纪录片）+ zhihu（深度科普）+ generic 兜底

**安全教育组合**：smartedu（安全教育）+ bilibili（动画）+ ximalaya（故事）+ generic 兜底

## 四、查询数量分配

### 标准模式

| 平台优先级 | 查询数 |
|-----------|-------|
| P0（核心） | 3-5 个 |
| P1（重要补充） | 2-3 个 |
| P2（兜底覆盖） | 1-2 个 |
