# 学习资源来源与平台判断

本文件提供平台生态知识，帮助模型根据当前学习任务推导每个来源的贡献。

## 先从全网发现开始

### generic

通用搜索是每次搜集的第一来源。它能跨站发现：

- 官方或公共教育资源、博物馆、图书馆、大学和专业机构内容；
- 文章、图文解释、练习、活动、讲义、课件和具体文件；
- 尚未接入独立搜索适配器的平台公开页面；
- 适合孩子直接使用的材料，以及家长用于选择和陪伴的方法。

generic 应用多条互补查询建立来源和资源形态的基础覆盖。通用结果仍需 Selector 审查，搜索排名不等于质量。

## 再判断专业平台的独特价值

选择前依次判断：资源由谁使用、要完成什么学习行为、哪种媒介确有帮助、该平台能否提供 generic 难以稳定获得的内容。没有独特贡献的平台不加入。

### smartedu

长于结构化的学段学科课程和公共教育资源。适合需要系统课程、知识点学习或结构化材料的任务。站内分类和版本信息只有与 Intent 一致时才作为查询条件。

### bilibili

长于过程演示、画面解释、朗读示范、动画、纪录片和连续视频内容。适合视觉信息或连续讲解能明显帮助当前学习的任务，查询应聚焦这种独特作用。

### ximalaya

长于朗读、跟读、故事、听书、儿歌和连续音频。适合声音本身是学习内容，或通勤、睡前、低屏幕使用等场景。依赖图形、书写和步骤观察的任务通常不能只靠音频。

### zhihu

长于方法解释、经验比较、资源线索和家长视角讨论。主要补充家长“怎样选择、怎样陪伴、怎样理解问题”，不代替孩子直接使用的学习材料。只有当前任务确有家长方法需求时才加入。

### douyin

长于短时间展示单个动作、步骤或兴趣切面。适合可以在较短内容中清晰呈现的局部目标；系统性目标需要由其他来源共同支持。

### weibo

长于机构发布、主题活动、公开资料线索和时效信息。通常是追踪来源或活动的补充，不是稳定的核心学习材料库。

### open163

长于公开课、纪录片、讲座及较深入的人文和科学内容。适合理解能力匹配的孩子、青少年，或家长陪伴下的拓展学习。

## 独立任务与网页发现

语义判断完成后读取 `../config/platform-catalog.json`：

- 只有 `planning_status=available` 的平台可以成为独立任务。
- `auth` 只说明执行条件，认证信息不写入计划。
- 只使用 catalog 声明的真实参数。
- planned 或未列入 catalog 的来源可以由 generic 搜索公开网页，例如使用普通关键词或适当的 `site:` 查询。

Catalog 是执行边界，不是平台选择算法。平台组合应由当前任务需要的资源作用决定。
