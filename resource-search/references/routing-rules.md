# 平台路由与内容优势

本文件帮助模型判断一个需求更适合去哪些平台搜索。它提供语义线索，不是固定映射表。

## 判断顺序

1. 先理解用户想通过资料完成什么：看懂、听读、练习、跟做、查方法、找素材或打印使用。
2. 用户明确指定平台、资料形态或来源时优先响应。
3. 用户没有指定时，根据主题本身常见的学习方式选择主力平台。
4. 再选择能增加新形态、新来源或新理解角度的平台作为补充。
5. 最后固定增加 generic，通过百度和 Bing 做全网补充。

平台数量不需要固定。一个窄需求可能只需要一个专项平台加 generic；宽泛主题可以使用多个互补平台。不要平均搜索所有平台。

## 平台语义画像

### bilibili

- 擅长：系统讲解、知识动画、过程演示、兴趣课程、系列合集、纪录片。
- 适合：需要“看懂”“看过程”“用画面解释”的需求。
- 搜索角度：动画、讲解、课程、合集、具体问题、实验或操作过程。
- 注意：碎片视频和完整课程混在一起；必须官方、必须文档或必须打印时不能独自承担需求。

### ximalaya

- 擅长：儿童故事、古诗国学、朗诵、儿歌、听书、磨耳朵、系列音频课。
- 适合：睡前、通勤、跟读、背诵、听故事和语言输入。
- 搜索角度：故事、朗诵、跟读、音频、专辑、儿童、睡前听。
- 可用参数：按专辑或单集搜索、免费过滤、相关度/热度/最新排序。
- 注意：不适合依赖图形、书写步骤或视觉演示的任务。

### smartedu

- 擅长：官方课程、教材同步、学段学科资源、课件、教案、练习。
- 适合：课内同步、明确年级或教材版本、官方课程、教师备课资料。
- 搜索角度：学段、年级、学科、知识点、版本、册次。
- 注意：“小学”“数学”“语文”等词本身不代表用户需要教材同步。只有这些维度能改善当前检索时才选择或细化。

### zhihu

- 擅长：学习方法、家长和教师经验、资源推荐、问题解释、避坑和观点比较。
- 适合：用户想知道“怎么学”“怎么教”“为什么”“有什么推荐”。
- 搜索角度：真实问题句、方法、经验、推荐、比较。
- 注意：内容偏成人视角，不应默认作为孩子直接使用的主要学习资料。

### douyin

- 擅长：单一技巧、动作示范、短步骤、趣味启发和快速展示。
- 适合：短时间能说明白的操作、动作、记忆技巧和手工步骤。
- 搜索角度：短主题、技巧、示范、快速、教程。
- 注意：不适合系统课程或需要完整论证的内容。

### weibo

- 擅长：机构发布、资料分享线索、主题活动和时效信息。
- 适合：寻找机构账号、活动资料和公开分享线索。
- 搜索角度：机构名、主题、资料、分享、活动。
- 注意：需要登录态，内容不稳定，不适合作为系统学习的主力来源。

### open163

- 擅长：公开课、纪录片、大学课程、人文与通识内容。
- 适合：高龄儿童或家长共同观看的深度科普、人文历史和艺术内容。
- 搜索角度：公开课、纪录片、讲座、课程。
- 注意：许多内容面向成人。低龄启蒙和小学同步任务通常不是它的优势。

### generic

- 擅长：跨站发现、未接入平台、机构网站、长尾网页、文档和具体文件格式。
- 适合：所有需求的全网补充，尤其是原文、讲义、活动方案、可打印资料和可信站点。
- 搜索角度：主题本身、资料用途、内容形态、具体文件格式，以及适合时的 `site:`、`filetype:`。
- 注意：搜索结果来源复杂，质量由后续 Selector 判断。

## 主题组合参考

这些组合用于提示可能的方向，不是必须选择的平台清单。

- 古诗/国学：音频朗诵和跟读常由 ximalaya 承担；动画、意境和赏析可由 bilibili 承担；原文注释与其他资料由 generic 补充。
- 科普启蒙：bilibili 适合动画和实验过程；高龄深度内容可以考虑 open163；百科、博物馆和活动资料由 generic 扩展。
- 学科练习：明确课内同步时考虑 smartedu；解题过程可以增加 bilibili；练习题、试卷和文件由 generic 扩展。
- 学习方法：zhihu 适合家长和教师经验，bilibili 适合可视化示范，generic 用于补充其他教育站点。
- 故事和语言输入：ximalaya 通常是主力；用户需要画面时再增加 bilibili。
- 手工、运动和技能：bilibili 适合完整教程，douyin 适合单一动作示范，generic 补充图文步骤。

模型可以根据具体主题形成这些组合之外的方案。平台是否加入，取决于它能否为当前需求提供独特价值。

## 通用搜索

每份计划包含一个 generic 任务。每一次 generic 搜索的 `params.engines` 同时写入 `baidu` 和 `bing`。

通用搜索应补充专项平台没有覆盖的方向，而不是把所有平台关键词原样再搜一遍。例如专项平台已经搜索“古诗朗诵专辑”和“古诗动画”，generic 更适合搜索“古诗原文 注释 译文”或具体文件和站点。
