# 搜索策略指南

> 本文件是 resource-search 阶段的核心策略指南，用于制定搜索计划：选哪些平台、用什么关键词、各平台搜多少、怎么组合。
> 执行层面的细节（怎么搜、怎么去重、怎么评分）见 resource-platforms 阶段的文档。

## 一、核心原则

1. **搜得到是第一优先级**：多来源、多查询、多角度并行，宁可多不可漏。
2. **用户指定优先**：用户明确说要什么类型（视频/文档/音频等），就以该类型为主，其他类型作为补充。
3. **主题自适应**：不同主题的资源形态分布不同，不搞一刀切，根据主题特点调整各形态的搜索比重。
4. **尽量多搜，不预设难度**：不要因为"文档类难获取""音频站反爬"就少搜，搜了再说，能拿多少算多少，标注清楚获取难度即可。

## 二、平台路由判断

搜索的第一步不是立刻开搜，而是**先判断应该去哪些平台搜**。选对平台，事半功倍。

### 路由判断流程

```
拿到需求
    ↓
1. 看用户有没有明确指定平台/类型
    ↓ 有 → 直接去对应平台
    ↓ 没有 → 继续
2. 判断主题类型（科普/学科/古诗...）
    ↓
3. 查平台优势图谱，选第一梯队平台（2-3个）
    ↓
4. 根据资源形态偏好，补充对应平台（1-2个）
    ↓
5. 通用搜索补充（百度+必应全网扫一遍，固定执行，非条件触发）
    ↓
确定平台组合，生成搜索任务清单
```

### 怎么选平台组合？

**第一步：看用户指定**
- 用户说"去B站找" → 直接B站为主
- 用户说"要文档" → 百度文库+官方站为主
- 用户说"要听的" → 喜马拉雅为主

**第二步：按主题类型选第一梯队**
参考 `../config/platform-advantages.md` 第三节，选该主题的第一梯队平台（2-3个）。

**第三步：按资源形态补充**
如果用户有明确的形态偏好，或者主题的第二/第三形态也很重要，补充 1-2 个对应平台。

**第四步：通用搜索补充（固定步骤，非条件兜底）**
平台专属搜完后，用通用搜索（百度+必应）全网扫一遍，防止漏网之鱼。无论平台搜了多少结果，这一步始终执行。

### 常见平台组合（参考）

| 场景 | 主力平台 | 补充平台 |
|------|---------|---------|
| 大多数需求 | B站 + 喜马拉雅 | 知乎/小红书 + 通用搜索 |
| 学科同步 | 国家中小学智慧教育平台 + 百度文库 | B站 + 知乎 + 通用搜索 |
| 古诗国学 | 喜马拉雅 + B站 | 百度文库 + 通用搜索 |
| 科普启蒙 | B站 + 网易公开课 | 喜马拉雅 + 知乎 + 通用搜索 |
| 安全教育 | 学校安全教育平台 + B站 | 喜马拉雅 + 通用搜索 |

> 💡 **详细的平台优势、适合场景、优先级，见 `../config/platform-advantages.md`**

### 路由判断原则

1. **用户指定优先**：用户说要什么平台/类型，就直接去
2. **主题匹配优先**：根据主题类型，选最擅长的平台
3. **3-5个平台足够**：不要所有平台都搜一遍，重点搜最匹配的
4. **灵活调整**：搜了发现某个平台结果特别好，可以多搜；结果不好就少搜
5. **通用搜索必做**：平台专属搜完，一定要用通用搜索（百度+必应）全网再扫一遍，防止漏网。这是路由计划的固定一步，不是失败降级

> 💡 **核心思路**：把精力放在最可能出好结果的平台上，而不是平均用力每个平台都搜一点。

## 三、资源三层分层定位

### 第一层：质量标杆层（第一类官方站）
- **定位**：真正有系统学习资源的官方/专业站，质量最高
- **占比**：候选的 10-15%（虽然少，但都是精品）
- **特点**：有成体系的课程/资源，不是零散文章或新闻
- **核心站点**（3个，必搜）：
  - 国家中小学智慧教育平台：学科同步类首选
  - 学校安全教育平台：安全教育类首选
  - 网易公开课：科普、人文、艺术类首选
- **使用方式**：每个主题优先搜这 3 个，定向查询 2-3 个
- **站点清单与搜索技巧**：见 `../config/site-whitelist.md` 第一类

> 💡 **重要**：不是所有官方站都在这一层。很多官方站主要是新闻、活动、宣传，系统学习资源很少，不值得重点搜。

### 第二层：数量主力层（视频平台）
- **定位**：资源数量主力，覆盖最广，质量也不错
- **占比**：候选的 55-65%
- **特点**：内容丰富、形式多样、更新快、系统动画/课程多
- **核心平台**：
  - B站（哔哩哔哩）：长视频、系统课程、科普动画、番剧
  - 抖音/西瓜视频：短视频、碎片化知识点、趣味讲解
- **使用方式**：必搜，高优先级，专门做定向查询，筛选高赞/官方账号内容

> 💡 **关键**：视频平台是真正的资源主力，特别是科普、兴趣类主题，大部分优质资源都在这里。

### 第三层：长尾补充层（图文社区 + 通用网页 + 第二类官方站）
- **定位**：补充文档、练习题、经验分享，以及部分官方站资源
- **占比**：候选的 25-35%
- **特点**：文档类资源多、经验分享实用、质量差异大
- **核心来源**：
  - 知乎：深度经验、资源推荐、学习方法
  - 小红书：育儿经验、资源分享、图文教程
  - 通用网页：教育网站、文档分享站
  - 第二类官方站：科普中国、中国数字科技馆等（有好东西但得淘）
- **使用方式**：补充搜索，重点找文档/练习题类资源，第二类官方站主题匹配才搜

## 四、主题自适应资源形态策略

不同主题的资源形态分布差异很大，不能一刀切都以视频为主。模型需要根据主题类型，动态调整各资源形态的搜索优先级和查询数量。

### 优先级总原则
1. **用户指定优先**：用户明确说要什么类型，就以该类型为主，其他类型补充
2. **主题自适应**：用户没指定时，根据主题特点判断各形态的优先级
3. **全覆盖**：每个主题都要覆盖主要形态（视频、音频、文档、图文），只是比重不同
4. **不预设难度**：不要因为"文档难获取""音频反爬"就少搜，搜了再说

### 主题类型-资源形态优先级映射表

| 主题类型 | 第一优先级 | 第二优先级 | 第三优先级 | 典型例子 |
|---------|-----------|-----------|-----------|---------|
| 科普启蒙类 | 视频动画 | 图文百科 | 文档课件 | 宇宙、恐龙、科学实验、动物植物 |
| 学科同步类 | 文档课件 | 视频讲解 | 练习题 | 数学、语文、英语课内知识点 |
| 古诗/国学类 | 音频听读 | 视频动画 | 文档原文 | 唐诗、三字经、论语、成语故事 |
| 思维训练类 | 视频讲解 | 练习题 | 图文教程 | 逻辑思维、数学思维、编程启蒙 |
| 艺术美育类 | 视频教程 | 图文作品 | 文档教案 | 画画、音乐、书法、手工 |
| 习惯品格类 | 音频故事 | 视频动画 | 图文经验 | 情绪管理、社交、生活习惯、安全 |
| 兴趣拓展类 | 视频教程 | 图文经验 | 文档资料 | 棋类、航模、运动、乐高 |

### 查询数量分配建议（标准模式，共10-15个查询）
- **第一优先级形态**：3-4个查询
- **第二优先级形态**：2-3个查询
- **第三优先级形态**：1-2个查询
- **官方站定向**：2-3个查询（第一类官方站必搜）
- **通用/长尾**：2-3个查询

### 形态判断要点

**怎么判断主题属于哪种类型？**
- 看核心诉求是"看"还是"听"还是"读/练"
- 看孩子的使用场景（看动画、磨耳朵、做练习）
- 拿不准就按"均衡型"处理，每个形态都搜2-3个

**如果某类形态搜不到好结果怎么办？**
- 不要硬凑，如实标注该形态资源较少
- 可以适当增加其他形态的查询数量
- 在结果中说明"XX类资源较少，主要为XX类"

## 五、高级搜索语法

### 1. site: 定向搜索
在指定站点内搜索，精准度最高。
```
site:basic.smartedu.cn 四则混合运算
site:bilibili.com 太空科普
site:zhihu.com 小学数学资源推荐
```

### 2. filetype: 文件类型搜索
指定文件格式，找文档类资源专用。
```
filetype:pdf 三年级数学练习题
filetype:ppt 恐龙科普课件
filetype:doc 语文教案
```

### 3. intitle: 标题限定
要求关键词出现在标题中，提高相关性。
```
intitle:四则混合运算 练习题
intitle:太空知识 科普
```

### 4. 双引号精确匹配
要求关键词完整出现，不被拆分。
```
"四则混合运算" 练习题
"太空知识" 儿童科普
```

### 使用建议
- 官方站优先用 site: 定向
- 文档类必加 filetype:pdf/doc/ppt
- 核心主题词加双引号提高精准度
- 组合使用：`site:xxx.com filetype:pdf "关键词"`

### 5. 跨平台资源形态策略

**按形态分平台定向（通用原则）：**
- **视频类**：务必对视频平台做定向查询，通用搜索里视频结果容易被淹没。
- **音频类**：古诗、国学、故事类主题，务必对音频平台做定向查询，音频资源丰富且适合孩子磨耳朵。
- **文档类**：文档类资源获取难度较高（很多需付费/登录），但也要尽量多搜——能拿到多少算多少，标注清楚获取难度即可。免费预览版也算，可让用户看到内容概览。

> 💡 **各平台专属搜索技巧**：见 `../config/platform-mapping.md` 和各平台的详细文档。

## 六、多引擎互补策略

### 主引擎：百度（70% 权重）
- 优势：中文资源覆盖最广、国内站点收录最全
- 适用：通用搜索、文档搜索、国内站点定向

### 补充引擎：必应（20% 权重）
- 优势：英文资源好、广告少、结果质量较高
- 适用：补充搜索、交叉验证、百度结果少时使用

### 平台站内搜索（10% 权重）
- B站站内搜索：视频类必用
- 知乎站内搜索：经验分享类必用
- 优势：平台内排序更精准、有播放量/点赞数参考

### 使用策略
1. 先用百度主搜（通用搜索先跑，全网扫一圈发现优质站点）
2. 关键主题用必应交叉验证（补充百度未收录的结果）
3. 针对通用搜索发现的优质站点 + 已知平台，做平台站内定向搜索
4. 不要只依赖一个引擎

## 七、双模式搜索开关

### 标准模式（默认）
- **适用场景**：常规需求、用户没说要"尽量多"
- **查询数量**：10-15 个查询
- **来源覆盖**：3 类以上
- **预期候选**：20-25 个（含 S/A/B 级）
- **平台数量**：3-5 个平台

### 穷尽模式
- **适用场景**：用户明确要求"多找点""尽量全""所有相关的"
- **查询数量**：20-30 个查询
- **来源覆盖**：5 类以上
- **预期候选**：30-40 个（含 S/A/B 级）
- **平台数量**：5-7 个平台

### 切换规则
- 用户说"多找点""尽量全""所有相关的" → 自动切换穷尽模式
- 用户说"先看看""推荐几个" → 标准模式
- 默认 → 标准模式

> 💡 **核心思路**：穷尽召回供用户自己选，而不是模型提前筛选掉大部分。
> 只过滤明显垃圾的，质量一般的也保留并标注，把选择权交给用户。

## 八、搜索任务输出规范

resource-search 阶段的最终输出是**搜索任务清单**（stage2_search_plan.json），包含：

1. **平台列表**：选了哪些平台，优先级是什么
2. **各平台查询词**：每个平台用哪些关键词搜
3. **各平台目标数量**：每个平台期望返回多少结果
4. **策略说明**：为什么选这些平台、为什么用这些关键词

> 📖 详细的输出格式规范，见 `../schemas/skill-contract.md`。
