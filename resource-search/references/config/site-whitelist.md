# 优质站点白名单

> 本白名单收录经过核验的儿童教育资源站点，按实际资源价值分为三类，不是所有官方站都值得搜。
> 用于搜索策略制定时的平台选择和定向搜索。

---

## 使用说明

- 🟢 **第一类：真·系统学习资源站** → 必搜，资源质量高、成体系
- 🟡 **第二类：有部分优质资源** → 主题匹配才搜，有好东西但得淘
- 🔴 **第三类：资源较少** → 一般不搜，除非主题特别匹配

搜索时使用 `site:域名 关键词` 语法定向搜索。

## 官方站内容筛选标准

**不是所有官方内容都是高质量的，要严格筛选：**

✅ **保留（S/A级）**：
- 系统课程、系列课、专题合集
- 互动学习资源、虚拟展厅、在线实验
- 纪录片、公开课（成体系的）

⚠️ **谨慎保留（B级）**：
- 单篇科普文章（除非特别好）
- 图文介绍、知识点汇总

❌ **直接过滤**：
- 新闻稿、活动通知、发布会
- 线下展品介绍、场馆介绍
- 卖书、卖课广告
- 领导讲话、工作动态
