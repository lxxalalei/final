# 平台能力清单

> 本文件列出所有可用平台的能力和特点，是 resource-search 阶段选择平台的参考依据。

---

## 概述

resource-search 在制定搜索策略时，根据平台的能力特点和优势领域，选择最合适的平台组合。

## 平台选择原则

1. **用户指定优先**：如果用户明确说了要去某个平台搜，直接用那个平台
2. **主题匹配**：根据需求主题，从平台优势图谱中选择最匹配的 3-5 个平台
3. **形态补充**：根据资源形态偏好，补充对应类型的平台
4. **通用兜底**：通用搜索引擎作为补充，防止漏网
5. **状态检查**：只选择状态为"可用"的平台，规划中的平台可以用通用搜索替代
