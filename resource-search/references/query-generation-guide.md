# 查询生成指南

> resource-search 参考文档。从 intent 的结构化需求出发，按五维拆解生成差异化查询指令。查询扩展的唯一信息源。

---

## 一、五维拆解法

任何需求均从以下 5 个维度拆解，每个维度生成对应查询方向。

### 维度 1：核心主题

- **基础关键词**：用户原话中的核心主题词
- **同义词/别称**：同一主题的不同常用说法
- **细分方向**：主题包含的主要子领域
- **上位概念**：所属的更大范畴
- **下位概念**：更具体的细分知识点

示例（太空知识）：
- 基础：太空知识
- 同义词：宇宙科普、天文入门、航天科普
- 细分方向：太阳系、黑洞、空间站、行星、航天发展史
- 上位：科学科普
- 下位：八大行星、月球、火星、载人航天

> 📖 各主题的完整扩展词表见第三节。

### 维度 2：资源形态

核心主题词 + 形态限定词，定向挖掘不同类型资源。

核心形态扩展词：
- 视频：课程、讲解、纪录片、动画、教学视频
- 文档：PDF、课件、教案、讲义、电子书
- 练习题：习题、练习册、试卷、作业
- 图文：文章、教程、百科、知识点整理
- 图片/图集：挂图、插画、思维导图
- 音频：故事、儿歌、听书、音频课
- 实验/手工：教程、步骤、方案

### 维度 3：受众与难度

核心主题词 + 受众/难度限定。

难度档位：入门/零基础、儿童/小学生、进阶/提高、系统/完整、通俗/趣味

### 维度 4：来源倾向

核心主题词 + 来源限定。

来源类型：官方、教育部、中科院、学校、名师、名校、人教版、部编版

### 维度 5：使用场景

核心主题词 + 场景限定。

常见场景：入门教程、系统学习、教案、教学设计、练习题、测试卷、科普、拓展阅读、小实验、手工、活动方案、亲子游戏

## 二、查询四级分类

### 【核心查询】（tier: core，优先级最高，必须搜）

- 核心主题 + 常用形态 + 基础难度
- 最能代表用户需求的 2-3 个查询
- 下游 platforms 必须执行，且要多来源覆盖

示例：
- 儿童音乐启蒙动画
- 幼儿乐理入门视频

### 【官方定向】（tier: official，去白名单官方站点搜）

- 核心主题 + 官方/权威来源限定
- 配合 `site:域名` 语法在白名单站点内定向搜索

示例：
- `site:basic.smartedu.cn 三年级数学`
- `site:open.163.com 儿童太空科普`

> 📖 白名单站点清单见 `./site-whitelist.md`

### 【形态定向】（tier: format，分别限定不同资源形态）

- 核心主题 + 单一形态限定
- 每个主要形态至少 1 个查询
- 可配合 `filetype:` 语法搜索特定文件格式

示例：
- （视频）儿童音乐启蒙教学视频
- （文档）`filetype:pdf 幼儿乐理教案`
- （图文）儿童音乐启蒙方法

### 【长尾补充】（tier: longtail，优先级较低，有空再搜）

- 上位概念、冷门角度、细分方向
- 用于扩充召回，提升穷尽度
- 下游 platforms 时间不够可以跳过

示例：
- 奥尔夫音乐教学法 儿童
- 儿童节奏感训练

## 四、高级搜索语法

用于 `generic` 平台（百度/必应）和官方定向查询（tier: official）。

### site: 定向搜索

在指定站点内搜索：

```
site:basic.smartedu.cn 四则混合运算
```

### filetype: 文件类型搜索

指定文件格式：

```
filetype:pdf 三年级数学练习题
filetype:ppt 恐龙科普课件
```

### 双引号精确匹配

要求核心关键词完整出现：

```
"四则混合运算" 练习题
```

### 组合使用

```
site:basic.smartedu.cn filetype:pdf "三年级数学"
```

> ⚠️ 这些语法在通用搜索引擎中有效；各平台站内搜索的语法以平台自身能力为准。

## 五、主题类型与资源形态优先级

| theme_type | 第一优先级形态 | 第二优先级形态 | 第三优先级形态 |
|------------|-------------|-------------|-------------|
| 科普 | 视频动画 | 图文百科 | 文档课件 |

| 古诗语文 | 音频听读 | 视频动画 | 文档原文 |

## 六、搜索模式与查询数量

### 标准模式（默认）

| 查询类型 | 数量 |
|---------|------|
| core（核心查询） | 2-3 个 |
| official（官方定向） | 2 个 |
| format（形态定向） | 3-4 个 |
| longtail（长尾补充） | 3-6 个 |
| **总计** | **10-15 个** |

### 穷尽模式

| 查询类型 | 数量 |
|---------|------|
| core（核心查询） | 3-5 个 |
| official（官方定向） | 3-4 个 |
| format（形态定向） | 5-8 个 |
| longtail（长尾补充） | 9-13 个 |
| **总计** | **20-30 个** |

## 七、质量自检清单

生成 search_tasks 前逐项核对。

### 数量与覆盖

- ✅ 总数量 ≥ 10 个（标准模式）或 ≥ 20 个（穷尽模式）
- ✅ 覆盖至少 3 种资源形态
- ✅ 包含至少 2 个难度档位
- ✅ 包含至少 1 个官方/权威来源定向
- ✅ 包含核心主题的同义词/别称扩展

### 查询分级

- ✅ core 查询 2-3 个（标准）或 3-5 个（穷尽）
- ✅ official 查询 1-2 个（标准）或 3-4 个（穷尽）
- ✅ format 查询每个主要形态至少 1 个
- ✅ longtail 查询 3-6 个（标准）或 9-13 个（穷尽）

### 查询质量

- ✅ 没有高度重复的相似查询
- ✅ 没有过于宽泛、匹配度极低的查询
- ✅ 每个查询标注了 tier 和 format_hint
- ✅ 关键词针对各平台做过适配优化
- ✅ 年龄适配词已添加
