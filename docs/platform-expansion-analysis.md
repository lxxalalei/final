# 平台拓展分析报告

> **目的**：评估项目可拓展的资源平台，并按搜索接口调用难易度分级，为后续 platform skill 开发排序提供决策依据。
>
> **当前已接入 5 个平台**：bilibili（P0）、smartedu（P1）、zhihu（P2）、douyin（P2）、weibo（P2）。
>
> **生成时间**：2026-06-25

---

## 一、搜索接口调用难易度分级标准

| 等级 | 含义 | 典型特征 |
|------|------|---------|
| ⭐ 极易 | 直接 HTTP 即可拿到结构化数据 | 公开 JSON API，无登录、无签名、无强风控 |
| ⭐⭐ 较易 | 需简单处理但稳定可达 | 需固定 UA/Cookie、或解析页面 JSON、或注册开放平台 key |
| ⭐⭐⭐ 中等 | 需专门绕过轻度反爬 | AJAX 接口需构造参数、有频率限制、部分内容需登录 |
| ⭐⭐⭐⭐ 较难 | 强反爬，需签名/浏览器 | WBI/ABogus 等动态签名、CDP 浏览器、Cookie 频繁失效 |
| ⭐⭐⭐⭐⭐ 极难 | 多重防护 + 付费墙 | 加密流、设备指纹、风控验证码、内容付费 |

> 经验值：已接入的 bilibili（WBI 签名 + CDP）和 douyin（ABogus + f2 引擎）属于 ⭐⭐⭐⭐；smartedu（Access Token + m3u8 加密）属于 ⭐⭐⭐；zhihu/weibo 属于 ⭐⭐⭐。

## 三、按"搜索接口调用难易度"详细分析

### 🟢 第一梯队：极易调用（⭐）— 优先接入

#### 1. 网易公开课 `open163` — **搜索难易度 ⭐**

| 维度 | 说明 |
|------|------|
| **搜索入口** | 课程详情页直接 requests 解析 JSON，参考开源项目 `JamesHoi/Open163-Downloader` |
| **认证要求** | 无需登录，课程列表和视频地址均公开 |
| **视频地址** | m3u8 直链，可用 ffmpeg 下载（项目已有 ffmpeg 能力） |
| **字幕** | 支持，可分别下载 |
| **儿童内容** | 科普纪录片、人文历史、TED 演讲，质量高但偏高年级 |
| **开发预估** | **1-2 天**即可完成 platform skill（搜索 + 下载 + 字幕） |
| **风险** | 部分国际课程（TED）需中文字幕匹配 |
| **接入建议** | ✅ **下一个首选接入平台**。无需 Cookie/签名，技术成本低，内容质量高，能立刻补齐"纪录片/公开课"形态 |

**核心 API 模式**（参考 Open163-Downloader）：
```
课程列表页 HTML → 解析内嵌 JSON → 获取 courseId
courseId → 请求章节 API → 拿到视频 m3u8 + 字幕地址
ffmpeg -i m3u8 -c copy output.mp4  # 项目已有能力
```

#### 2. 央视网 `cctv` — **搜索难易度 ⭐⭐**

| 维度 | 说明 |
|------|------|
| **搜索入口** | `vdn.apps.cntv.cn` API 返回视频真实地址（JSON） |
| **认证要求** | 无需登录，但需等待广告播放后才能抓到真实请求 |
| **视频地址** | 2021 年起隐藏真实地址，花屏防护，需专门处理解密 |
| **儿童内容** | 央视少儿频道、官方动画、科普纪录片，权威性最高 |
| **开发预估** | **3-5 天**（花屏解密是主要难点） |
| **风险** | 视频有花屏加密防护，需参考 vdn API + 解密逻辑 |
| **接入建议** | ✅ 推荐接入。权威儿童内容无可替代，但需投入解密工程 |

### 🟡 第二梯队：较易调用（⭐⭐）— 重点投入

#### 3. 喜马拉雅 `ximalaya` — **搜索难易度 ⭐⭐**

| 维度 | 说明 |
|------|------|

| **接入建议** | ✅ **P0 必接平台**。平台优势图谱已列为"古诗/国学/故事类首选"，音频形态目前是空白，补齐后产品能力大幅提升 |

**开放平台 API 能力清单**：
- `/search/albums` — 搜索专辑

- `/albums/{id}` — 专辑详情
- `/albums/{id}/tracks` — 专辑内声音列表
- `/tracks/{id}/audio` — 获取音频地址

## 六、结论与建议

### 6.1 最值得立即接入的 3 个平台

1. **网易公开课 `open163`** — 技术成本最低（⭐），内容质量高，2 天见效
2. **喜马拉雅 `ximalaya`** — 补齐音频形态空白，开放平台 API 规范
3. **央视网 `cctv`** — 央视少儿内容权威性不可替代

### 6.2 不建议优先投入的平台

- **百度文库 / 豆丁网**：付费墙太厚，投入产出比低
- **学堂在线 / 腾讯课堂**：内容偏成人，与儿童场景不匹配
- **豆瓣**：更适合做元数据（评分/简介）来源，而非主资源站

### 6.3 形态互补性分析

当前平台的形态覆盖：
- ✅ 视频（长）：bilibili
- ✅ 视频（短）：douyin、weibo
- ✅ 图文：zhihu、weibo
- ✅ K12 官方：smartedu
- ❌ **音频：完全空白**（ximalaya 是最高优先级）
- ❌ **纪录片/公开课：空白**（open163 填补）
- ❌ **官方动画：空白**（cctv 填补）
- ❌ **文档课件：空白**（baiduwenku 难度高，可降级为预览引导）

**核心建议**：优先补齐**音频（喜马拉雅）**和**纪录片（网易公开课）**两个形态空白，这两者技术难度都不高，投入产出比最优。
