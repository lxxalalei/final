## 措辞校准第二轮：步骤驱动风格（2026-06-26 21:20）

### 最终风格规范

| 结构要素 | 写法 |
|---------|------|
| 章节标题 | `## 读写文件`（intent 用 `## 写入文件`，无上游） |
| 步骤编号 | `### 1.` `### 2.` `### 3.` `### 4.` |
| 步骤1 | 获取任务路径——从 flow 参数获取 session_dir / 上游文件名 / 输出文件名 |
| 步骤2 | 读取上游 data（intent 无此步） |
| 步骤3 | 执行核心任务 + 写入结果文件（JSON 在这里出现） |
| 步骤4 | 完成后——提示 flow 调用下一个 Skill，只返回 _summary |
| 字段说明 | JSON 下方用 `-` 列表说明 _summary / data / 新增字段 / 保留规则 |
| 去掉的 | 字段表格、"flow 会给你…"的对话叙述、"禁止丢弃"措辞 |

### flow/SKILL.md 的步骤

flow 的"数据流转规则"也改为步骤驱动：`### 1. 创建会话` → `### 2. 调度每个阶段` → `### 3. 上下文管理` → `### 4. 需求类型判断`。
