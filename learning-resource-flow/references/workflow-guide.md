# 工作流详细指南与异常处理

## 需求澄清策略

### 必须澄清 vs 可选澄清

**必须澄清（缺失会显著影响结果）：**
- 孩子年龄或年级 → 直接影响资源难度匹配
- 具体学习主题 → 直接影响搜索相关性

**可选澄清（有默认值）：**
- 资源形式 → 默认综合推荐（视频+文档+练习）
- 学习目标 → 默认练习/巩固
- 使用场景 → 默认家庭学习

### 澄清话术示例

**信息完全缺失时：**
```
为了给您找到最合适的资源，想确认几个问题：
1. 孩子今年几岁/几年级？
2. 具体想找哪方面的学习资源？（比如数学的某个知识点、科普主题等）

如果您不确定或想让我先按通用情况搜索，也可以直接说"先搜搜看"，我会采用合理的默认值。
```

**部分信息缺失时：**
```
我理解您要找[主题]相关的资源，还想确认一下：
1. 孩子今年几岁/几年级？（方便我匹配难度）

其他信息我会按默认处理，有问题随时调整。
```

### 用户跳过澄清时的默认假设

当用户说"先搜搜看"或跳过某些问题时，采用以下默认值并明确告知：

- **年龄/年级**：假设小学2-3年级（8岁左右）
- **资源形式**：综合推荐（视频+文档+练习题）
- **学习目标**：练习巩固
- **使用场景**：家庭自主学习

**必须在结果中明确写出假设：**
```
💡 本次搜索采用的默认假设：
- 孩子年龄：8岁左右（小学2-3年级）
- 资源类型：综合推荐
如果需要调整，请告诉我。
```

## 候选展示策略

### 排序优先级

> 📖 **质量评估与排序的完整标准见** [`../../shared/schemas/quality-rubric.md`](../../shared/schemas/quality-rubric.md)
>
> 以下为 flow 视角的要点速览，评分维度、权重、等级映射一律以权威文件为准。

候选资源排序分两层：

**第一层：质量等级（S → A → B → C）**

质量等级由五维评分加权计算得出，详细规则见权威文件。

**第二层：同级别排序**

同等级内的排序优先级（主题相关性 → 可获取性 → 内容完整度 → 适龄精准度 → 互动数据）同样见权威文件第七节。

> ⚠️ 五维评分维度、权重、S/A/B/C 等级判定标准、同级别排序规则等**均不在本文件中重复定义**，统一以 [`../../shared/schemas/quality-rubric.md`](../../shared/schemas/quality-rubric.md) 为准。

## 用户确认交互

### 确认选项

展示候选后，提供以下选项：

1. **全部获取**：下载/保存所有候选资源
2. **选择获取**：用户指定编号（如"1、3、5"）
3. **搜索更多**：继续搜索更多候选
4. **调整条件**：修改搜索参数后重新搜索
5. **取消**：结束任务

### 用户选择后的处理

**全部获取：**
- 直接进入资源获取阶段
- 批量处理所有候选

**选择获取：**
- 解析用户选择的编号
- 只处理选中的资源
- 未选中的资源不下载

**搜索更多：**
- 继续调用 resource-search，使用不同关键词或来源
- 追加展示新的候选
- 注意去重，避免重复展示

**调整条件：**
- 重新澄清需要调整的参数
- 重新执行搜索
- 展示新的候选列表

## 异常处理

### 搜索无结果

**处理方式：**
1. 扩大搜索范围（放宽关键词、增加同义词）
2. 调整适龄范围
3. 改变资源类型
4. 如果仍无结果，如实告知并给出建议

**话术示例：**
```
抱歉，没有找到完全匹配的资源。可能的原因：
1. 主题比较小众或专业
2. 适龄范围太窄

建议：
- 可以放宽年龄范围试试
- 或者换个相关的关键词
- 我也可以帮您找一些相关的通用资源

您想怎么调整？
```

### 获取全部失败

**处理方式：**
1. 分析失败原因（付费墙？需登录？链接失效？）
2. 给出具体的补救建议
3. 提供替代方案

**话术示例：**
```
这些资源暂时无法直接获取：

❌ [资源1] → 需要付费会员
   替代方案：我可以帮您找一些免费的同类资源

❌ [资源2] → 需要登录后才能下载
   补救步骤：您可以先登录该网站，然后告诉我，我再尝试获取

需要我帮您找一些替代的免费资源吗？
```

### 资料库检索命中

**处理方式：**
1. 优先展示已有资源
2. 说明是之前归档的
3. 询问用户是否需要，还是要找新资源

**话术示例：**
```
📚 在本地资料库中找到了相关资源：

1. [资源名] - 获取于 [日期]
2. [资源名] - 获取于 [日期]

这些是您之前保存的资源，需要直接使用吗？还是想再搜索一些新的？
```

## 归档前去重

### 自动去重检查

阶段五（归档与索引）在执行归档操作前，会自动运行跨平台内容级去重检查。去重引擎（`../../resource-platforms/scripts/shared/dedup.py`）按以下优先级检测：

1. **resource_id 完全一致** — 最强信号，直接判定重复
2. **内容指纹匹配**（MD5/SHA256）— 字节级精确匹配
3. **URL 结构化匹配** — 同一页面不同追踪参数视为重复
4. **标题相似度**（编辑距离 + TF-IDF）— 跨平台近似检测

检测到重复后，按 `dedup.strategy` 配置处理：

| 策略 | 行为 |
|------|------|
| `keep_best_quality`（默认） | 保留质量等级最高的版本 |
| `keep_earliest` | 保留最早获取的版本 |
| `keep_latest` | 保留最新获取的版本 |
| `mark_and_keep_all` | 全部保留，标记 `is_duplicate` |

### 用户可感知的去重反馈

当归档阶段跳过或替换了重复资源时，在阶段六（结果反馈）中体现：

```
✅ 资源获取完成

成功获取（X个）：
1. [资源名] → [保存路径]
2. ...

检测到跨平台重复（已自动处理）：
1. [资源名A（抖音版）] 与已有 [资源名A（B站版）] 内容一致
   → 已跳过（保留 B站 S级版本）
2. [资源名B（知乎版）] 与已有 [资源名B（B站版）] 标题相似度 0.92
   → 已标记为重复版本
```

### 搜索停止条件

满足以下任一条件时停止搜索：
1. 已找到 8-10 个高质量候选（S级+A级）
2. 连续 3 次查询未产生新的有效候选
3. 达到调用次数或时间预算
4. 用户要求停止

### 获取并发控制

- 同时下载不超过 3 个资源
- 页面转换串行处理（避免触发反爬）
- 大文件下载预估时间，提前告知用户

## 安全与合规

### 内容安全过滤

儿童场景必须启用严格安全过滤：
- 过滤暴力、色情、恐怖内容
- 过滤明显的广告和诱导下载
- 过滤内容农场和低质量营销站
- 优先选择官方、教育类、知名平台

### 版权风险提示

对于以下情况需要明确提示版权风险：
- 第三方分享的网盘资源
- 可能涉及盗版的教材/课件
- 用户上传的非官方内容

**提示话术：**
```
⚠️ 版权提示：
该资源为第三方分享，请注意：
1. 仅供个人学习使用
2. 请勿传播或用于商业用途
3. 建议优先支持正版资源
```

### 隐私保护

- 不记录用户的孩子姓名、学校等个人信息
- 资料库只存储资源文件和必要的元数据
- 不向第三方上传任何用户数据
